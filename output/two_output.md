## Experiment 1: Subspace Overlap Across Layers

For head 0, extracted top-20 right singular vectors of each layer's attention kernel (W_Q_h^T @ W_K_h) and computed pairwise Grassmann similarity.

**Interpretation:**
- Uniformly high similarity → depth is redundant (layers query the same subspace)
- Block-diagonal structure → layers cluster into phases with sharp transitions
- Low off-diagonal → each layer queries a genuinely different subspace
